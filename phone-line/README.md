# קו Gemini Live לחברים ובני משפחה

הקו מזהה חבר רשום לפי מספר הטלפון. בפעם הראשונה נדרש אישור בהקשה לתנאי השימוש, למדיניות הפרטיות ולהקלטה הזמנית. האישור נשמר במסד מקומי. מתקשר שאינו רשום שומע הודעה ייעודית.

| שלוחה | מודל |
| --- | --- |
| 1 | Gemini 3.8 Live |
| 2 | Gemini 3.8 Live Extended Thinking |
| 3 | Gemini 3.1 Flash Live Preview |
| 4 | Gemini 2.5 Flash Native Audio Preview |
| 9 | מדיניות הפרטיות |

יעד SIP מספר 0 מפעיל את הבדיקה בכניסה, הפתיח והתפריט. אפשר גם לנתב ישירות ליעדי המודלים. כל יעד בודק רישום והסכמה לפני שליחת שמע ל־Gemini. טלפון חסוי או לא מזוהה מקבל את הודעת המספר הלא רשום. זיהוי זה נשען על אמינות זיהוי המתקשר שמגיע מימות המשיח.

## פרטי משתמש וניטור

הרשומה הפרטית כוללת שם פרטי, שם משפחה, מספר טלפון ומפתח API מוצפן. לעוזר מועבר רק השם הפרטי מתוך הפרופיל. שם פרטי עשוי כשלעצמו להיות מידע אישי, והפרדת שם המשפחה אינה מבטיחה עמידה בתנאי השירות החינמי של גוגל.

העוזר פותח בעברית, פונה בשם פרטי כשמתאים ועובר לשפת המשתמש כשהוא משנה שפה. כלי חדשות מספק כותרות ותקצירים. חיפוש Google מוגדר כגיבוי.

הניטור פועל כל 7 שניות על חלון של עד 12 שניות. ברירת המחדל לחסימה היא הסתברות של 97% ומעלה, בכל אחד מכללי המיניות, הצעקות והקללות. זו הסתברות שמדווח המודל, ודיוקה בעברית דורש בדיקות. בפיילוט כשל בשירות הניטור, לרבות מיצוי מכסה, מאפשר לשיחה להמשיך ולניטור לנסות שוב במחזור הבא.

זיהוי שחוצה את הסף עוצר את השיחה. הדוח כולל את סוג הכלל, תיאור השאלה שנבדקה, ההסתברות, מועד הזיהוי וחלון הזמן בשיחה. תיאור זה מגיע מכלל הניטור, והקלטת הקטע אינה נשמרת בדוח. השמע המלא נשמר זמנית בזיכרון עד סיווג הנושאים.

## הפעלת שרת הטלפוניה

1. התקן Python 3.12, את החבילות ב־`requirements.txt` ואת Asterisk עם תמיכת הודעות JSON ב־chan_websocket, למשל 22.8 ומעלה בסדרת 22.
2. הגדר `PHONE_MASTER_KEY` למפתח Fernet ואת `PHONE_ROSTER` לנתיב פרטי. הוסף משתמש עם `python phone_users.py "$PHONE_ROSTER" <number>`. הכלי מבקש שם פרטי ומשפחה ומפתח API. משתמשים קיימים מהגרסה הקודמת שומרים על מזהה המשתמש כאשר מעדכנים אותם, וצריך להשלים להם שמות.
3. הגדר `PHONE_REPORT_DB` לנתיב SQLite פרטי, `PHONE_PROMPT_DIR` לתיקיית ההקלטות ו־`PHONE_ASTERISK_PASSWORD` לסיסמת חיבור ייעודית. אותה סיסמה מופיעה בקונפיגורציה הפרטית של Asterisk. הרץ `python phone_gateway.py`.
4. העתק והתאם את דוגמאות Asterisk שבתיקיית `asterisk`. השירות מאזין על 127.0.0.1 בלבד. נתב את הכניסה הראשית ליעד SIP מספר 0. יש לאמת מול חשבון ימות המשיח העברת זיהוי מתקשר וחזרה לתפריט כשחיבור ה־SIP מסתיים.

`PHONE_MAX_CALL_SECONDS` קובע משך שיחה מרבי. ברירת המחדל בפיילוט היא 480 שניות. `PHONE_THRESHOLDS` מאפשר לעדכן את שלושת הספים ב־JSON. שמור את קובץ המשתמשים, מסד הדיווח, כתובות הטפסים והסודות מחוץ למאגר הציבורי.

## שליחה ישירה לשני טופסי Google

הדיווח נשלח ב־HTTPS POST ישירות ל־formResponse. הכלי קורא את דף הטופס ומחלץ את מזהי entry של שדות הטקסט.

טופס השיחות צריך להכיל שדות טקסט בכותרות הבאות.

| כותרת שדה | ערך |
| --- | --- |
| שם משתמש | שם פרטי ומשפחה |
| מספר טלפון | מספר המתקשר |
| תאריך ושעת התחלה | מועד תחילת Live |
| נושאי שיחה | JSON של הסיווג |
| עילת סיום | ניתוק, זיהוי חריגה, מכסה, שגיאה או הגבלת משך |
| משך שיחה | שניות |

טופס החריגות צריך להכיל שם משתמש, מספר טלפון, סוג החריגה, תאריך ושעת החריגה ופרטי החריגה. אפשר להוסיף שדות נפרדים לשם פרטי ומשפחה, מזהה שיחה ומודל.

חלץ ושמור מיפוי עם `python forms_export.py --calls-url <viewform> --violations-url <viewform> --output <private-config.json>`. הגדר את `PHONE_FORMS_CONFIG` לנתיב הקובץ. הטפסים צריכים לאפשר מענה לשרת באמצעות השדות האלה, ללא דרישת כניסה, וללא הגבלת תשובה אחת. תגובות הטפסים עצמן מיועדות למנהל בלבד.

דוח מקומי נשמר גם כששליחה אינה מאומתת. לכל טופס יש מצב שליחה נפרד. במצב עמום, למשל ניתוק אחרי שליחת הבקשה, הרשומה מסומנת uncertain וממתינה לבדיקה כדי למנוע ניסיון חוזר שייצור כפילות. שליחה ישירה אינה מספקת התחייבות שרת למניעת כפילויות. לשליחת רשומות שטרם נוסו הרץ `python forms_export.py --database "$PHONE_REPORT_DB"`.

## הקלטות

הפתיח נמצא ב־opening.wav ובחירת המודלים ב־models.wav. בעת שינוי במודלים מוקלט מחדש רק קטע המודלים. למדיניות הפרטיות נבחר Gemini 3.8 Flash-Lite TTS, וליתר ההודעות Gemini 3.8 Flash TTS.

הרצת 44186107501 השלימה opening, models, unknown-caller, call-limit, consent ו־privacy. המכסה מוצתה ב־policy-stop. יתר ההודעות ממתינות לחידוש. הריצה שמרה גם את המקור וגם את ההמרה הטלפונית ואת תמלילי הקבצים ב־artifact בשם gemini-live-phone-audio.

בהרצה חוזרת בוחרים את הענף gemini-live-phone ב־workflow הקיים של פודקי. הריצה משחזרת את חבילת השמע האחרונה, משתמשת בקבצים שהטקסט והמודל שלהם לא השתנו, ועוצרת עם שמירת התקדמות בעת תשובת 429. החבילה ב־GitHub נשמרת 30 יום. יש לגבות אותה לפני פקיעת התקופה. חידוש ההפקה הוא פעולה ידנית לאחר איפוס המכסה.

## בדיקות והשלמות אנושיות

`python -m unittest discover -s tests -v` מתוך תיקייה זו מפעיל בדיקות מקומיות עם שמע ותגובות API מדומים.

להפעלה חיה צריך להשלים במרוכז פרטי משתמשים ומפתחות, את שתי כתובות הטפסים, גישה לשרת SIP וחשבון ימות המשיח, הגדרות ספק, אישור האזנה להקלטות, וחידוש הפקת ההודעות החסרות לאחר איפוס המכסה. יש להשלים גם פרטי קשר למנהל וזמן שמירת נתוני הדיווח. חיבור כלי RSS ו־Google Search לכל מודל טעון בדיקה במפתח משתמש פעיל.
