# קו Gemini Live

שלוחות 1–4 ממופות בהתאמה ל־Gemini 3.8 Live, ‏Gemini 3.8 Live Extended Thinking, ‏Gemini 3.1 Flash Live Preview ו־Gemini 2.5 Flash Native Audio Preview. שלוחה 9 שמורה למדיניות הפרטיות של הקו.

## הרצה מקומית והרשמת משתמש

1. התקן Python 3.12 ואת החבילות ב־`requirements.txt`. השתמש ב־Asterisk עם `chan_websocket` ותמיכה בהודעות JSON, למשל 22.8 ומעלה בסדרת 22.
2. הגדר `PHONE_MASTER_KEY` כמפתח Fernet, שמור אותו מחוץ למאגר ובאותו מקום מוגן של הגדרות השירות. הגדר `PHONE_ROSTER` כנתיב לקובץ פרטי והרץ `python phone_users.py "$PHONE_ROSTER" <number>` כדי להוסיף או לעדכן משתמש. הקוד האישי ומפתח Gemini נקלטים באופן אינטראקטיבי.
3. הגדר `PHONE_ASTERISK_PASSWORD` לסיסמה ייעודית והכנס את אותו ערך בקובץ ההגדרות הפרטי של Asterisk. הגדר `PHONE_REPORT_DB` לנתיב SQLite ול־`PHONE_PROMPT_DIR` את תיקיית הודעות הקו ב־WAV מונו 8 קה״ץ, PCM16. `PHONE_THRESHOLDS` הוא JSON עם שלושת הספים `sexual_content`, `shouting` ו־`profanity`. כייל אותם עם דגימות מתוסרטות בעברית לפני שיחות אמת.
4. הרץ `python phone_gateway.py`. השירות מאזין בכתובת המקומית `127.0.0.1:8765`. העתק את קטעי הקונפיגורציה מהתיקייה `asterisk` לקבצים הפעילים. חבר את יעדי ה־SIP של שלוחות 1–4 להקשר `from-yemot-gemini` דרך חיבור הספק המאומת בלבד. אופן מיפוי היעדים וזיהוי המתקשר תלוי בהגדרת חשבון ימות המשיח. אמת בניסוי שכל יעד נכנס לשלוחה המתאימה ושהמתקשר חוזר לתפריט כש־Asterisk סוגר את רגל ה־SIP.

משך שיחה מרבי בפיילוט הוא 480 שניות כברירת מחדל. אפשר לשנות אותו באמצעות `PHONE_MAX_CALL_SECONDS` בטווח 60–900 שניות. לפני אישור בהקשה, השמע אינו נשמר ואינו נשלח ל־Gemini. אחרי האישור השמע נשמר בזיכרון, ובתום השיחה הוא נמסר לסיווג אחד ונמחק עם סיום העיבוד. נתוני הדיווח נשמרים ב־SQLite. החיבור לטופסי Google דורש את שלב הדיווח.

## הקלטות ובדיקות

ההקלטות החד־פעמיות מושהות כרגע. כשתתחדש ההפקה, בחר בענף `gemini-live-phone` בהרצת הקריינות הקיימת של פודקי. חבילת ההרצה כוללת קובצי WAV, תמלילים ותוצאות בדיקות Gemini. נוסח שלוחה 9 ממתין לפרטי מפעיל הקו ותקופת שמירת נתוני הדיווח.

מתוך תיקייה זו, `python -m unittest discover -s tests -v` מריץ בדיקת WebSocket מקומית עם שמע סינתטי. שיחה מול ימות המשיח והרשאות המודלים במפתחות המשתמשים דורשות בדיקה חיה. לפיילוט חינמי יש להשתמש בשמע מתוסרט ללא פרטים אישיים, חסויים או רגישים.
