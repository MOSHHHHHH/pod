# פתיח שמע לפודקי

הפתיח הוא צליל מקורי ועדין באורך של כ־2.1 שניות, המתווסף **לפני תחילת הפרק**.

## תמיכה
- MP3 מסוג MPEG-1 Layer III, סטריאו, בתדר 44.1 או 48 קה״ץ.
- ההוספה אינה משנה את קידוד השמע, ואת תגיות ID3 שומר מנגנון פודקי הקיים.
- קבצים לא נתמכים (למשל M4A, מונו, MP3 בתדר אחר), או קובץ פתיח חסר, נשמרים ללא פתיח כדי למנוע שיבוש.
- השינוי חל רק על הורדות חדשות. אין עריכה של קובצי עבר.
- הורדה מקוטעת שומרת גם את אורך הפתיח במצב החידוש.

## כיבוי והפעלה
ב־Apps Script > Project Settings > Script Properties:
- `PODKI_AUDIO_INTRO_ENABLED=false` — כיבוי הפתיח.
- `PODKI_AUDIO_INTRO_ENABLED=true` או מחיקת ההגדרה — הפעלה.

## שינוי הצליל
שנה את `scripts/generate_podki_intro.py` (תווים, משך ועוצמה).
GitHub Actions מייצר מחדש את הקבצים `assets/audio/podki-intro-44100-stereo.mp3` ו־`podki-intro-48000-stereo.mp3`.

**הגבלה חשובה:** חיבור מסגרות MP3 ללא קידוד מחדש מתאים רק לפורמטים התואמים; יש לבצע בדיקת האזנה וניגון של קובץ אמיתי לפני הפעלה רחבה.
