# Podki email mascot

Six transparent PNG assets, optimized to fit within 320×320 pixels. Used by the shared JS email wrapper. Gmail may require enabling remote images; email actions and text remain available without images.

- welcome.png — waving welcome
- search.png — curious, holding a magnifying glass
- catalog.png — holding catalog cards
- success.png — cheerful thumbs up
- waiting.png — calm, patient pose
- error.png — concerned and helpful, amber warning light

Created using OpenAI image generation. Base prompt: a friendly rounded cobalt-blue podcast robot, ivory face, dark expressive eyes, cyan accents, blue headphones, small luminous chest button; premium toy-like 3D illustration, full body, isolated transparent background, no text or logos. Each variant preserves the reference identity and changes only expression and pose as described above.

No changes are required to the GS loader. Assets are served from the public repository through jsDelivr.
